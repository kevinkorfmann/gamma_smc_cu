`default_flow_field.txt` is the numerical constant-population flow field from
Schweiger and Durbin's Gamma-SMC reference implementation:
https://github.com/regevs/gamma_smc/blob/main/resources/default_flow_field.txt

It is provided unchanged so the Python and native APIs can resolve the same
default without relying on a developer's filesystem. SHA-256:
`f612eac0a794f4b37374245a2035abdc2c2229cbb13b2409ac3f0eef37b51aaf`.

Please cite Schweiger and Durbin (2023) when using the Gamma-SMC model.
